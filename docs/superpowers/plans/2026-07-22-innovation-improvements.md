# YOLO 电池缺陷创新点改进计划

## 目标

在保持普通 YOLO11 基线路径不变的前提下，改进现有 DIDC、MCRD 和 CBSC：

- DIDC：从每批次两路反事实前向改为擦除/插入单路交替前向，保留目标变化监督，降低训练开销。
- MCRD：保留可解释几何关系解码，加入可配置的类别规则和形态约束，避免随机关系网络影响验证稳定性。
- CBSC：不再使用整图加滑窗裁剪的额外前向；改为 MDSC（形态—密度评分校准），在候选框级别单次前向完成校准。

## 实现边界

1. 先添加失败测试：DIDC 只调用一个反事实分支、MCRD 类别规则可改变关系决策、MDSC 改变候选排序且关闭时为恒等变换。
2. 修改 `DetectionTrainer` 与 `DetectionModel.loss`，让 DIDC 分支交替且只产生一条额外前向。
3. 修改 `mcrd.py`、`nms.py`，加入类别规则和形态/置信度保护，保留 `mcrd=False` 的原始 NMS 路径。
4. 新增 `utils/mdsc.py`，并将预测、验证和配置接入 `mdsc`；旧 `cbsc` 参数只作为兼容别名，不再触发裁剪训练/裁剪前向。
5. 更新本地 `train.py` 的开关和低开销默认值，使三模块可单独开启。
6. 运行模块测试、编译检查和一个极小数据训练/验证冒烟测试；不把冒烟结果当作精度提升结论。

## 验证标准

- `didc=False, mcrd=False, mdsc=False` 时输出与原始路径一致。
- DIDC 开启时每个批次只执行一次反事实 `predict`，且擦除/插入分支交替使用。
- MCRD 记录输入、解码后和最终候选数量，类别规则不会合并不同类别目标。
- MDSC 不构造裁剪图、不增加模型前向，输出候选仍经过标准 NMS。
- 训练/验证能够完成，未出现半精度输入与浮点权重不匹配或 NMS 超时刷屏。

## 研究表述

这些修改属于“拟提出/待验证”的工程实现。是否提高 mAP、是否减少误检以及是否值得作为论文贡献，仍需在固定数据划分、随机种子、训练预算和基线下完成消融实验后判断。

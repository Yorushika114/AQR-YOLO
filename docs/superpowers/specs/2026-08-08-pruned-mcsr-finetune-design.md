# 剪枝后 MCSR 模型恢复微调设计

## 目标

为 `tools/prune_mcsr.py` 生成的结构化剪枝权重增加独立恢复微调入口。微调必须直接训练 checkpoint 中保存的剪枝模型对象，不能根据原始 YAML 重新构建未剪枝网络。

## 范围

- 新增独立脚本 `tools/finetune_pruned_mcsr.py`。
- 输入为已经完成结构化剪枝的 MCSR `.pt` 权重和 YOLO 数据集 YAML。
- 支持常用恢复训练参数，以及 MCSR、SA-TAL 的训练开关。
- 输出沿用 Ultralytics 训练目录结构，生成 `best.pt`、`last.pt`、指标和训练日志。
- 不修改普通 `train.py`，不改变基线训练流程，不负责剪枝执行、ONNX/TensorRT 导出或部署测速。

## 关键问题

直接调用 `YOLO(pruned.pt).train(...)` 时，`YOLO.train()` 会调用训练器的 `get_model(weights=..., cfg=self.model.yaml)`。剪枝 checkpoint 的 YAML 仍描述原始通道宽度，因此该路径可能重建未剪枝结构，再将能够匹配的权重载入，导致真实剪枝结构丢失。

## 方案

### 1. 剪枝权重检查

脚本加载 checkpoint 后执行以下检查：

- checkpoint 包含 `pruning` 元数据；
- 模型最后一层仍为带 MCSR 路由器的检测头；
- 当前参数量等于剪枝报告中的 `after_params`；
- 当前参数量小于剪枝报告中的 `before_params`；
- 模型类别数与数据集配置能够在训练器初始化阶段保持一致。

不符合要求时立即报错，避免把普通权重误当成剪枝权重微调。

### 2. 结构保持型训练入口

脚本直接创建 YOLO 检测训练器，然后在训练开始前把已加载的剪枝 `nn.Module` 注入 `trainer.model`。`BaseTrainer.setup_model()` 遇到现成的 `nn.Module` 会跳过 YAML 重建，从而保持全部剪枝通道和 MCSR 路由结构。

训练器接收标准 Ultralytics 参数，包括数据集、轮数、批次、图像尺寸、设备、workers、优化器、学习率、warmup 和输出目录。默认采用较低初始学习率进行恢复微调，不在脚本中冻结 MCSR。

### 3. MCSR 与 SA-TAL

- MCSR 属于 checkpoint 中的网络结构，微调前检查路由器存在，并允许其参数继续更新。
- SA-TAL 属于正样本分配与损失路径，通过 `sa_tal` 和 `sa_size` 传入训练配置。
- 脚本不新增其他创新模块，也不改变 MCSR 或 SA-TAL 的数学逻辑。

### 4. 保存与结构复核

训练完成后：

- 要求 `best.pt` 或 `last.pt` 至少存在一个；
- 重新加载最终 checkpoint；
- 比较微调前后总参数量，必须完全一致；
- 检查 MCSR 路由器仍然存在；
- 将原始剪枝报告、微调参数量和来源 checkpoint 路径写入最终训练 checkpoint 的元数据；
- 返回训练目录、最佳权重路径和结构复核结果。

参数量变化视为结构被重建或错误替换，脚本以非零状态退出，不宣称微调成功。

## 使用方式

脚本顶部提供便于直接修改的默认路径，同时保留命令行参数覆盖能力。推荐流程为：

1. 使用 `tools/prune_mcsr.py` 生成剪枝权重；
2. 修改微调脚本顶部的权重和数据集路径；
3. 直接运行 `python tools/finetune_pruned_mcsr.py`；
4. 使用输出目录中的 `best.pt` 进行正式验证。

## 错误处理

- 权重或数据集文件不存在：训练前报错。
- 输入不是带元数据的剪枝 checkpoint：训练前报错。
- MCSR 路由器缺失：训练前报错。
- 微调后参数量变化：训练后报错，并保留训练目录供排查。
- 没有生成权重：训练后报错。
- 微调权重无法重新加载：训练后报错。

## 测试与验收

自动化测试覆盖：

1. 普通未剪枝权重被拒绝；
2. 合法剪枝 checkpoint 能通过检查；
3. 训练器注入后持有的对象就是剪枝模型，不调用 `get_model()` 重建；
4. 训练配置能够传递 MCSR/SA-TAL 参数；
5. 微调结果复核能够识别参数量恢复问题；
6. 微调后权重可重新加载，参数量不变且路由器存在。

连通性测试采用小图像和最短训练配置验证数据加载、前向、反向、验证和 checkpoint 保存。正式精度恢复仍需使用实际数据集与完整微调轮数确认。

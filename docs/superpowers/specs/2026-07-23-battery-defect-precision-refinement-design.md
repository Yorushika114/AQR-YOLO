# 电池表面缺陷三模块精度增强设计

日期：2026-07-23

## 1. 背景与目标

当前 YOLO11n 电池表面缺陷检测实验已经启用三个研究模块：

- MDRH：形态驱动路由检测头；
- BCRH：中心/边界响应辅助头；
- CDAA：类别密度自适应任务分配。

目标是在保持当前训练速度约 1 分钟/轮的前提下，优先提升 `Surface_Crack` 的定位质量和 mAP50-95，同时保持 Pinhole、Delamination 以及总体指标不明显退化。

## 2. 约束与非目标

- 不替换三个创新点，不新增 P2 检测层、大型注意力模块或额外前向分支。
- 保留三项开关及干净 YOLO11 基线路径。
- 保持数据集划分、输入尺寸、batch、优化器、epoch 和验证流程不变。
- 精度提升必须通过消融实验确认，不能把训练时间或随机波动造成的变化当作模块收益。

## 3. 方案设计

### 3.1 MDRH：局部形态路由

当前 MDRH 的路由器经过全局池化，为每个检测尺度生成一个统一的点/线/区域权重。这会使同一尺度内的针孔和裂纹共享路由，降低混合缺陷场景的适应性。

改为在保留现有三条形态分支和全局路由的基础上，加入由三条分支局部响应能量形成的逐位置路由：

```text
点分支、线分支、区域分支
        ├─ 全局路由先验
        └─ 局部响应能量 ── softmax ── 逐像素形态融合
```

局部路由只使用已有分支输出的通道均值/绝对值和 softmax，不新增卷积层。原始特征仍通过有界残差门控保留。

### 3.2 BCRH：多尺度边界门控

当前 BCRH 使用一个共享标量控制三个检测尺度。修改为每个检测尺度一个独立的零初始化门控参数，使浅层细节、 中层结构和深层语义可以分别学习边界响应强度。

监督仍保持中心响应和边界响应两个通道。在现有平衡 BCE 之外增加轻量软 Dice 项，降低边界目标稀疏时的类别不平衡影响。BCRH 仍然只从检测特征生成响应，不改变标注格式。

### 3.3 CDAA：形态感知正样本分配

当前 CDAA 已经使用类别稀有度、局部密度和目标长宽比补偿。进一步在任务对齐度中加入预测框与真实框的长宽比一致性，使细长裂纹的候选框不会仅因 IoU 较低而被过早排除。

该项只在 `cdaa=True` 时生效；`cdaa=False` 时保持原始 Task-Aligned Assigner 计算完全不变。

## 4. 配置建议

初始实验建议使用：

```yaml
mdrh: true
bcrh: true
cdaa: true
bcrh_dice_weight: 0.25
cdaa_shape_weight: 0.20
```

如果训练时间超过当前约 1 分钟/轮，优先降低 `bcrh_dice_weight`，不直接删除 MDRH 或 CDAA。

## 5. 验证策略

代码测试：

1. MDRH 输出形状、局部路由权重归一性和残差门控范围；
2. BCRH 多尺度门控、软 Dice 损失和反向传播；
3. CDAA 细长目标的候选分配以及默认关闭时的基线一致性；
4. 三模块联合的 YOLO11 前向、损失和反向传播。

实验测试：

- 基线；
- 三模块原实现；
- 仅 MDRH 增强；
- 仅 BCRH 增强；
- 仅 CDAA 增强；
- 三模块增强联合。

所有实验使用相同随机种子和训练预算。至少记录整体及各类别的 Precision、Recall、mAP50、mAP50-95、Params、GFLOPs 和每轮训练时间。

## 6. 验收标准

- 训练速度保持在当前约 1 分钟/轮附近，不出现数量级变慢；
- 所有模块测试和验证脚本测试通过；
- 总体 mAP50-95 不低于当前结果；
- `Surface_Crack` 的 mAP50-95 或 Recall 至少有一项稳定改善；
- 改进不能依赖改变数据划分、验证参数或置信度阈值。

# YOLO 电池表面缺陷创新模块设计

## 目标

在保持默认 YOLO11 检测结构和输出行为不变的前提下，为电池表面缺陷检测提供三个可独立开关的模块：DIDC 训练辅助、MCRD 候选框关系解码和 CBSC 多视图裁剪融合。

## 架构

DIDC 位于训练数据和损失路径，通过共享 YOLO 权重处理原图、框引导擦除图和插入图，并复用现有检测损失计算三个视图；同时加入编辑区域外稳定性和目标响应方向约束。MCRD 位于检测头输出和 Hard-NMS 之间，提供可解释的几何规则版和可注入训练式关系解码器。CBSC 位于训练和预测视图包装层，负责重叠裁剪、全局坐标映射、跨视图一致性损失和候选框融合，不改动 Backbone 或 Neck。

```text
训练：原图/擦除图/插入图 -> 共享 YOLO11 -> 检测损失 + DIDC 差分约束
训练：整图/重叠裁剪图 -> 共享 YOLO11 -> 检测损失 + CBSC 响应/类别一致性
预测/验证：整图/重叠裁剪图 -> 共享 YOLO11 -> 全局坐标映射 -> 跨视图融合 -> MCRD -> Hard-NMS
```

## 组件边界

- `ultralytics/data/didc.py`：检测标签和图像的确定性反事实视图构造。
- `ultralytics/utils/mcrd.py`：候选框关系特征、规则解码、重复框融合和独立目标保留。
- `ultralytics/utils/didc.py`：DIDC 编辑区域外稳定性和目标响应差分损失。
- `ultralytics/data/cbsc.py`：裁剪元数据、训练视图、框坐标往返映射和跨视图候选框融合。
- `ultralytics/utils/cbsc.py`：CBSC 一致性损失以及预测/验证共用的多视图后处理。
- 训练、验证、预测文件只负责接线，不复制上述算法。

## 开关和兼容性

三个开关默认关闭。`mcrd=False`、`cbsc=False` 时必须复用现有路径；`didc=False` 时必须只计算现有检测损失。新增模块不放入模型 YAML，因此普通权重加载、导出和基线消融保持兼容。

## 验证边界

当前代码已验证坐标映射、反事实目标数量、DIDC 辅助损失反向传播、CBSC 训练一致性损失、候选框关系、学习式 MCRD 损失、预测/验证共享后处理和开关一致性。训练收益、误检率、小目标召回、延迟、FPS、显存变化以及三模块联合消融仍属于待实验测量内容，不能在代码完成时宣称已经改善。
